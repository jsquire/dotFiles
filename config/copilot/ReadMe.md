# GitHub Copilot

### Overview

Included in this section are the personal instructions used to configure GitHub Copilot CLI across repositories.

The development bootstrap for each supported operating system installs these instructions when the current user does not already have a personal instruction file.  Repository instructions and skills may add more specific guidance when working within an individual project.

### Items

* **copilot-instructions.md**  
  _Authored in 2026, this file defines personal defaults loaded by GitHub Copilot CLI from `$HOME/.copilot/copilot-instructions.md`.  The current guidance directs explicit C# and .NET project creation requests to the installed `jesse-csharp` template._
