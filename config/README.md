# Shared Configuration

### Overview

Included in this section are configuration and source assets shared across operating systems.

The platform-specific bootstraps reference these files rather than maintaining separate copies.  This keeps personal instructions, project templates, and other user-scoped development defaults consistent across environments.

In some cases, the artifacts may be a subset of functionality, requiring use in a specific way or order to be helpful, where others may be a fully automated and self-contained process.  Please remember that these were written for practical personal use and are not intended to be examples of best practice, nor polished and production-ready.

### Structure

* **copilot**  
  _Authored in 2026, this directory contains personal instructions installed for GitHub Copilot CLI by the supported development bootstraps._

* **templates**  
  _Authored in 2026, this directory contains source and packaging assets for personal project templates installed into user-scoped template registries._
